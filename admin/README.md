# Awesome Handmade Enterprise Admin Dashboard

This directory contains the Admin Panel for the Awesome Handmade E-commerce Platform.

## Features
- **Dashboard & Real-time Analytics**: Sales, top sellers, order volume, live conversion.
- **Product Management**: Simple & Variable product creator, automated variant matrix generator, batch image assigner.
- **Category & Taxonomy Management**: Multi-level categories, subcategories, brands, attributes.
- **Order & Inventory Management**: Live stock tracking, warehouse allocation, status updates.
- **Customer & Review Control**: Customer CRM, review moderation, wishlist & cart analytics.
- **Promotions & Marketing**: Dynamic coupons, rule-based discounts, banner management.
- **RBAC & System Controls**: Roles, granular permissions, audit logs, global settings.
